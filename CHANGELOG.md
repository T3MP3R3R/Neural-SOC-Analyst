# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0-poc] - 2026-06-13
### Added
- Initial Proof of Concept release of the N.S.A Dashboard framework.
- Core Flask backend architecture and asset routing engine.
- Groq LLM integration layer optimized with defensive JSON parsing error fallbacks.
- ReportLab automation engine for dynamic incident PDF compilation.
- Automated testing suite containing 42 active unit test checkpoints.
- Docker Compose multi-service container configuration templates.

### Changed
- Migrated legacy `setup.txt` installation layout into a standardized markdown `README.md`.
